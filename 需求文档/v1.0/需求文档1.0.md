# 需求文档

>  当前项目的版本号1.0.0

## 1、项目架构

​	前端使用Preact10技术，前端页面的css参考static\styles.css文件，使用Tauri2技术进行打包，打包要考虑win+mac+linux全平台，win平台提供exe安装程序，mac提供dmg格式安装包，linux提供deb、rpm、tar.gz三种格式的安装包。静态资源存放目录为static（内部包含ico文件-用于安装程序的图标、前端页面的全局字体）
## 2、项目要求实现的功能：
1. 要有工作目录和输出目录（均可供用户自行选择），工作目录初始值为当前用户的Downloads目录，输出目录初始值为当前用户的Desktop目录。**重点要求：工作目录里面只识别PDF格式的发票文件，其他PDF一律不识别。**

2. 主页面布局严格按照我提供的来，如图（标黄色的为按钮，绿色为下拉选择框）![image-20260610155526656](需求说明/主界面.png)


3. 按钮功能解释说明

   1. 第一个浏览按钮：点击此按钮，调用系统内置的资源管理器浏览功能，供用户选择目录
   
   2. 第二个浏览按钮：点击此按钮，调用系统内置的资源管理器浏览功能，供用户选择目录
   
   3. 打开工作目录：点击此按钮，在当前系统的资源管理器中打开用户已选择的工作目录
   
   4. 打开输出目录：点击此按钮，在当前系统的资源管理器中打开用户已选择的输出目录
   
   5. 发票导入：点击此按钮，根据选择的工作目录，只识别目录内PDF格式的发票文件，并将导入的结果按行展示在表内
   
   6. 清空导入：点击此按钮，清空已经导入的全部发票。**注意，这一步不是清空工作目录内PDF格式的发票文件**
   
   7. 查看报销类别：点击此按钮，弹出一个页面，已只读的形式打开config目录下面的mapping.json，并将查询到的结果进行展示。界面如图
      ![image-20260610155526656](需求说明/报销类别查看.png)
   
   8. 导入报销类别：点击此按钮，将待导入的json文件进行验证，如果验证无误则显示导入成功；如果有误直接弹出导出错误对话框（无须给出错误的具体提示）
   
   9. 导出报销类别：点击此按钮，将config目录下面的mapping.json进行导出
   
   10. 修改报销类别：点击此按钮，弹出一个页面，已读写的形式打开config目录下面的mapping.json，并将当前json内的数据进行展示。界面如图：
   ![image-20260610172247650](需求说明/报销类别修改.png)
   
       其中新增映射规则按钮点击后，在当前表的最下面插入一行，项目名称、通用项目名称、大类别默认为空，由用户手动输入，报销类别由用户下拉选择（取值为config\category.json内的字段）
   
   11. 全部：点击此按钮，展示全部的已经导入的发票
   
   12. 可报销：点击此按钮，筛选报销类别不为空的明细并进行展示
   
   13. 不可报销：点击此按钮，筛选报销类别为空的明细并进行展示
   
   14. 项目名称选择框：点击此下拉框，读取全部明细里面的项目名称，做唯一性保留，由用户下拉选择（默认为空且只能唯一选择，用户未选择的情况下表示筛选全部）
   
   15. 筛选项目名称：点击此按钮，根据用户点击的全部/可报销/不可报销按钮+选择的项目名称，来筛选并展示对应的明细
   
   16. 报销类别选择框：点击此下拉框，根据config目录下面的category.json内的报销类别，提供下拉框供用户选择（默认为空且只能唯一选择）
   
   17. 一键设置类别：点击此按钮，根据用户选择的序号按钮以及选择的报销类别，对结果界面进行报销类别字段的更新
   
   18. 输出费用台账：点击此按钮，根据提供的模板，按报销类别进行汇总，并输出为xlsx格式的Excel文件
   
   19. 输出报销封面：点击此按钮，根据提供的封面模板，按报销类别进行汇总，并输出为pdf格式的文件
   
   20. 输出汇总PDF：点击此按钮，把PDF进行合并操作。每2个PDF合并为一个PDF，页面布局为竖向1×2，对齐方式为水平居中、上下居中
   
   21. 清空：点击此按钮，清空处理日志


4. 展示界面说明
![image-20260610155526656](需求说明/发票布局.png)

根据上方提供的发票布局模板，使用PDF识别工具，识别需要的字段

  + 序号（序号前面要有复选框供用户选择，为后续的修改报销类别和台账、封面、汇总PDF的输出做准备）
  + 发票类别：二选一，只有普通发票和专用发票两个类别
  + 开票日期：严格按照PDF文件内的开票日期来，例如：2026年05月26日
  + 发票号码：取PDF文件内的发票号码
  + 发票金额：取PDF文件内的小写价税合计
  + 购买方：取PDF文件内的购买方名称
  + 项目名称：取PDF文件内的项目名称
  + 报销归属：用于汇总费用台账、报销封面等归类，默认为空

5. config目录内mapping.json和category.json的关系：mapping里面报销类别的字段，仅能取category.json里面已有的值，请开发的时候严格按照这个逻辑
